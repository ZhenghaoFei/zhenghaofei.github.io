# Zhenghao Fei — Personal Page

Source for [zhenghaofei.github.io](https://zhenghaofei.github.io), built with Jekyll (GitHub Pages builds it automatically on push).

## Writing a new blog post

1. Copy `_drafts/TEMPLATE.md` into `_posts/`.
2. Rename it to `YYYY-MM-DD-your-post-title.md`.
3. Edit the title and write your content in Markdown.

The post is added to the home page automatically.

To list an external blog, create a post file with `external_url:` in the front matter and an empty body (see `_posts/2026-08-28-umi-lerobot.md`).

## Local preview

```
jekyll serve
```

then open http://localhost:4000
